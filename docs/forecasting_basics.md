# Forecasting Basics

The project includes a basic Holt-Winters / Exponential Smoothing revenue forecast.

## Why Use It Here?
The synthetic dataset contains:
- trend
- recurring monthly seasonality

The method provides a simple way to demonstrate:
- time aggregation
- train/fitted model workflow
- future-period generation

## Limitations

A production forecast should consider:
- holdout validation
- MAPE / MAE / RMSE
- external drivers
- promotions
- holidays
- structural breaks
- product changes
- uncertainty intervals
- forecast bias

This portfolio project demonstrates forecasting fundamentals, not a validated production demand forecast.
