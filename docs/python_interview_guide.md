# Python / Pandas Interview Guide

## Pandas
Be prepared to explain:
- DataFrame vs Series
- `.loc` vs `.iloc`
- `groupby`
- `merge`
- `concat`
- missing values
- duplicates
- sorting
- date handling
- pivot tables

## NumPy
Understand:
- arrays
- vectorised operations
- broadcasting
- numerical efficiency

## Performance
Prefer vectorised operations where practical.

Avoid unnecessary row-by-row loops on large datasets.

## Functions
Reusable functions improve:
- testing
- readability
- maintainability
- automation

## Analytics
Know:
- mean / median
- standard deviation
- percentiles
- correlation
- outliers
- sampling
- train/test thinking for predictive work
