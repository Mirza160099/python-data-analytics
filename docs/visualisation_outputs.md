# Visualisation-Ready Outputs

The pipeline creates files ready for Power BI, Tableau, Excel or Python plotting:

- `operations_clean.csv`
- `revenue_by_region.csv`
- `revenue_by_product.csv`
- `revenue_by_channel.csv`
- `monthly_summary.csv`
- `statistical_summary.csv`
- `correlation_matrix.csv`
- `revenue_forecast_3m.csv` after running the forecasting pipeline
