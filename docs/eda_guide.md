# Exploratory Data Analysis Guide

## 1. Dataset Shape
Start by checking:
- row count
- column count
- data types
- missing values
- duplicates

## 2. Univariate Analysis
Review distributions for:
- revenue
- profit
- units
- discount
- inventory
- lead time
- satisfaction
- delivery delay

## 3. Categorical Analysis
Compare:
- region
- product
- channel

## 4. Bivariate / Relationship Analysis
Explore:
- units vs revenue
- discount vs profit
- lead time vs satisfaction
- delivery delay vs satisfaction

## 5. Time Series
Review:
- monthly revenue
- monthly profit
- units sold
- seasonal patterns

## 6. Business Questions
- Which products drive revenue?
- Which regions outperform?
- Does discounting reduce margin?
- Are delays associated with lower satisfaction?
- Where does inventory appear excessive or constrained?
